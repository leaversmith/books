# Books

The household reading list, to be served at [leaversmith.com/books](https://leaversmith.com/books/) once GitHub Pages is enabled on this repository.

The list itself lives in `books.yaml`. Add a book under `queued`, `reading`, `paused` or `finished`. When a finished book has sat long enough, move it under `archive` for that year. Optional fields are `audio: true` and `review`.
